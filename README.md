# Kauã — After Dark

Portfólio de Kauã Everton de Lira com direção visual inspirada no universo Batman. Projetos, tecnologias, biografia, foto e contatos foram integrados a partir do portfólio anterior fornecido pelo usuário.

## Executar

Requer Node.js. Execute `node server.mjs` e abra http://127.0.0.1:4173. Arquivos estáticos prontos em `dist/`; nenhuma compilação necessária.

## Estrutura

- `dist/index.html`: apresentação, Nexus IoT, Moretti, POPs Nazca, tecnologias, perfil e contatos.
- `dist/app.js`: GSAP/ScrollTrigger e Three.js, com suporte a movimento reduzido e descarte de recursos.
- `dist/style.css`: direção visual e layout responsivo.
- `dist/vendor/`: bibliotecas locais, com GSAP 3.13.0 e Three.js 0.170.0 em uso. Swup 4.8.1 foi preservado, mas não é carregado: a navegação atual usa uma única página, após a remoção do laboratório.
- `dist/assets/gotham.png`: imagem original gerada por IA para esta versão.

## Referências de direção de arte

- https://territorystudio.com/project/the-batman/ — linguagem de interfaces e atmosfera.
- https://www.wearebond.com/case-studies/thebatman — experiência de exploração.

Essas referências orientam a direção visual. A cidade foi gerada para o conceito e o batarangue é uma geometria procedural original. Logotipos de projetos e retrato pessoal foram copiados do portfólio anterior com autorização do usuário. Google Fonts fornece Barlow Condensed, DM Sans e Space Mono; fontes locais de sistema servem de fallback.

Os links de projetos, repositórios, LinkedIn e o perfil GitHub de contato foram preservados como constavam no portfólio anterior. GSAP e Swup constam nas tecnologias por indicação do usuário. O projeto anterior permanece inalterado.
